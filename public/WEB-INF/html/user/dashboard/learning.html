나의 학습평가

    보완이 필요한 절차

    진행 중인 평가의 미통과 문항만 표시합니다.

      평가 규정

      1. 정기평가: 연 2회
        상시평가: 별도 운영
      2. 해당 평가의 모든 교육 완료 후 최초 평가 20문항에 응시합니다.
      3. 오답 관련 교육과 미통과 문항 재시험을 반복합니다.
      4. 최초 20문항을 모두 통과하면 합격합니다.
      출제 방식

      누적 오답률이 높은 문항은 새로운 최초 평가에 선정될 확률이 높아집니다. 재시험에서는 최초 선정 문항 중 미통과 문항만 출제합니다.
