# 작성 규칙

- 답변은 간단하게 작성한다.
- 웹표준과 웹접근성을 준수하고 JavaScript를 사용한다.
- 반응형은 Mobile First 및 `min-width` 기준으로 작성한다.
- vendor 라이브러리는 공식 라이브러리를 사용한다.
- 화면 전용 클래스보다 구조 기반 선택자를 우선한다.
- 재사용 가능한 UI는 기존 공통 클래스를 먼저 확인하고 우선 적용한다. 구조 기반 선택자 우선 원칙은 공통 클래스로 처리되지 않는 내부 요소에 적용한다.
- CSS 작성 전 reset 및 공통 스타일을 확인한다. 이미 적용되는 선언은 컴포넌트·페이지 CSS에서 중복 정의하지 않으며, 실제 값 변경이 필요한 경우에만 재정의한다.
- 모든 UI 아이콘은 `resources/user/css/icons.css`에서 CSS 마스크(`mask`, `-webkit-mask`)와 가상 요소로 구현한다. SVG 파일 경로는 CSS에서만 참조하고 HTML에 아이콘용 `<img>`, 인라인 `<svg>`, `<use>`, `<object>`를 삽입하지 않는다.
- 아이콘은 `data-icon`과 `::before`를 사용한다. 색상과 크기는 기존 Semantic 토큰을 사용하며, 장식용 요소는 `aria-hidden="true"`, 아이콘만 있는 버튼은 접근 가능한 이름을 제공한다.
- 로고·캐릭터 등 콘텐츠 이미지는 아이콘 규칙에서 제외한다.
- 상세 UI 규칙은 `UI 컴포넌트 작성 규칙.md`를 따른다.
